# TDD Discount Calculator

Пет-проект демонстрирующий разработку через тестирование (TDD) на TypeScript.

## Стек

- TypeScript
- Vitest

## Правила расчёта скидки

| Сумма заказа | Скидка |
|---|---|
| до 1000₽ | 0% |
| от 1000₽ до 4999₽ | 5% |
| от 5000₽ | 10% |
| VIP клиент | +5% |
| Максимум | 20% |

## Методология TDD

Проект написан строго по циклу **Red → Green → Refactor**:

- 🔴 **Red** — сначала пишется тест, который падает
- 🟢 **Green** — пишется минимальный код чтобы тест прошёл
- 🔵 **Refactor** — код улучшается, тесты остаются зелёными

Каждый цикл зафиксирован отдельным коммитом — история коммитов отражает весь процесс TDD.

## Тестовая пирамида

Проект покрыт unit-тестами — основанием тестовой пирамиды.

```
      / E2E \
     /-------\
    / Integr. \
   /-----------\
  /   Unit ✅   \
 /________________\
```

## Принципы SOLID в коде

Функция `calculateDiscount` разбита на три вспомогательные функции по принципу **Single Responsibility**:

- `getBaseDiscount` — считает базовую скидку по сумме заказа
- `applyVip` — применяет VIP надбавку
- `capDiscount` — ограничивает итоговую скидку максимумом
